## What 1.3.0 adds (per the published readme)

- `read_outline(result_id)` returns the result's heading tree (Markdown ATX headings or,
  for a PDF source, its font-size-calibrated heading structure) without returning the
  full body; `read_outline(result_id, node_id)` mints a `read_result`-compatible cursor
  anchored at that heading, so a long result can be jumped into directly instead of only
  advancing sequentially through `next_cursor`. An empty or absent outline is reported
  explicitly and never blocks reading the result with `read_result`.
- URL-result local hydration: URL and authorized local file sources are handled through
  the same `parse(source)` call, and a URL parse result can be re-read locally like a
  file result.
- `uninstall --yes --json` removes a trusted 1.2.2 **or** 1.3.0 Bridge entry and
  restores a matching trusted URL-only entry when available.
