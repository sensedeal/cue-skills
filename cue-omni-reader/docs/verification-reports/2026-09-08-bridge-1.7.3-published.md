## License correction

Bridge 1.7.3 is a metadata-only release: the package `license` field is corrected from `UNLICENSED` to `MIT` and the version advances `1.7.2 → 1.7.3`. npm will not republish an already-existing version with changed content, so the license fix ships as a new patch release rather than a same-version overwrite. There is **no protocol, tool-surface, or parsing change**: the tool surface stays the frozen seven and the local `src/path-security.ts` extension allowlist is unchanged from 1.7.2 (it accepts archive formats `rar`/`tar`/`tgz`/`gz`/`bz2`, plain-text formats `tsv`/`json`/`yaml`/`yml`/`toml`/`xml`/`ini`/`cfg`/`conf`/`log`, the RDF family `rdf`/`ttl`/`nt`/`n3`/`jsonld`, and FreeMind `mm`; `parquet` and mind-map containers `xmind`/`mmap` remain deliberately unsupported). The trusted managed-entry pair advances to 1.7.2/1.7.3; the only bare-`npx` Windows migration exception remains 1.5.1.
