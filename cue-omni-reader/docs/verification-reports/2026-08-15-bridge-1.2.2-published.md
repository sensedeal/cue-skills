1.2.2 is a config-transaction hardening release with no new CLI arguments and the same
wire/tool-surface contract as 1.2.1. It:

- adds a trusted-predecessor upgrade path so an existing audited 1.2.1 install is
  recognized and can be cleanly upgraded to 1.2.2 (and rolled back), rather than being
  treated as an unrecognized/untrusted entry;
- fixes `doctor` to report the actually-configured installed version instead of
  misreporting the target version;
- verifies existing-backup provenance (digest match against the currently-installed
  trusted entry) before rebinding it during an upgrade, closing a stale/tampered-backup
  rebinding gap;
- makes the config-file rename the final throwing step of every write transaction, so a
  failure after that point can never leave an untracked partial state requiring manual
  recovery;
- fixes a Hermes-target rollback that was previously a no-op after a failed health check.

`uninstall --yes --json` now removes a trusted 1.2.1 **or** 1.2.2 Bridge entry.
