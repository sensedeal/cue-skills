# 节模板 · 管理人尽调 · 登记与合规（1 页）

| 槽 | 填法 |
|----|------|
| 节名 | 管理人尽调底稿 · 登记与合规节 |
| 主体 | 登记全称 + 登记编号（多命中则拒写判断，先消歧） |
| 判断 ≤3 | ①是否在册及类型可写入 ②公开特殊/诚信提示位（仅公开页，≠无处罚/准入） ③公开机构提示是否需知会（升格另判） |

| 还开 | 产品清单节；公开处罚检索节（长窗） |
| 带走 | 并进「管理人尽调 → 登记与合规」 |
