# cue-section-registration（登记与合规节）

从协会公开登记数据吐出「管理人尽调 · 登记与合规」一节（≤3 判断 + 边界），并在**用户 Agent 工作区**建最小底稿壳或并入已有壳。

## 安装

```sh
npx skills add sensedeal/cue-skills --skill cue-section-registration
```

需要 `CUE_API_KEY`（与 cue-data-mcp 同一钱包）。禁止把 key 贴进对话。

## 一句话价值

同一协会字段，自由 Agent 易写成「合规良好 / 尽调通过」；本 skill 强制节形 + 禁句 + 先节后壳。
